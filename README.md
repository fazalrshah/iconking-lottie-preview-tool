# IconKing – Free Lottie preview tool

Upload a Lottie JSON and instantly preview it in the browser, then share a link (unlimited) — free.

👉 https://www.iconking.net/preview-lottie-free

## Why this exists
Lottie exports are often slow to verify and share. IconKing makes it quick to check timing/behavior and send a preview link to teammates or clients.

## Use cases
- QA after exporting from After Effects
- Sharing previews without sending JSON files
- Hand-off for designers/devs (Figma workflow, etc.)
